This is the first Post on the Blog. It is a sample that shows how a Post looks while the Site is under construction.

## What the Site is

The Site is one public place for writing, and later for a CV and Projects. From here you can go back to [Home](/) or to the list of all [Posts](/_/blog/).

## How it is built

- Every page is prerendered to plain HTML, so it reads without JavaScript.
- Each Post is a Markdown file with a title, a description and a publish date.
- GitHub Pages serves the pages as static files, under `/_/`.

The Site is built with [TanStack Start](https://tanstack.com/start). More Posts will follow.
